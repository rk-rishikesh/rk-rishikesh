I've spent years on every side of a hackathon, competing in them, judging them, mentoring the teams, and running developer programs that filled them. Loops.House is what I built after seeing the same problem from all four angles: hosting a great event is mostly unglamorous operational work, and judging it fairly at scale is close to impossible by hand.

So I'm automating both.

## 🌀 Loops.House

**Agentic hackathon hosting platform.** Hosts spin up an event, builders submit, and AI agents do the heavy lifting alongside human judges, so organizers run bigger events with less overhead and every submission gets a fair, consistent read.

- **AI-assisted judging** — submissions scored against configurable rubrics, paired with human judge evaluations rather than replacing them
- **Full event lifecycle** — configuration, submissions, judging, leaderboards, and finalization, with permissions gated by event phase
- **Enriched project profiles** — built automatically from GitHub repos, demo videos, and screenshots
- **Semantic search across submissions** — RAG-powered Q&A over project codebases and sponsor docs
- **Analytics for organizers** — submission stats, category and tech-stack breakdowns, momentum scoring
